## Overview

D16 Group Sigmund is a multi-tap delay processor with analog-inspired filtering and a vintage digital character, offering up to four independently controllable delay taps.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Sigmund** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Taps** | Up to four delay taps with independent time, level, pan, and filter |
| **Vintage Character** | Early digital aliasing and saturation for authentic retro delay tone |
| **Tempo Sync** | Lock delay times to BPM with standard and dotted note divisions |
| **Modulation** | LFO-driven delay time and filter for subtle chorus-like effects |
